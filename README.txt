# R&R Bake at Home — Free Website

This is a simple static website for R&R Bake at Home.

## Files
- `index.html` — website page
- `style.css` — design and responsive layout
- `logo.png` — your business logo

## Free hosting
You can publish this website for free using GitHub Pages, Netlify, or Cloudflare Pages.

### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload `index.html`, `style.css`, and `logo.png`.
4. Open the repository's **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/root`, then save.
6. GitHub will give you a free website address such as:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

A custom address such as `RRbakeathome.com` normally requires purchasing/renewing the domain separately.
